# Hi, I’m Jed

I build practical, local-first software across Apple platforms, automation,
media workflows, and careful web tooling. I enjoy turning ambiguous, real-world
processes into small tools that are understandable, reviewable, and safe to
operate.

## Selected projects

- [Notre-Dame Reservation Helper](https://github.com/jedison/notre-dame-reservation-helper) — a local Chrome extension for monitoring availability in an already-verified reservation session, with explicit stop conditions for site protections.
- [NoSideMediaManager](https://github.com/jedison/NoSideMediaManager) — a macOS media-metadata tool with an optional iPhone companion app, designed around reviewed TVDB/TMDB plans and portable, reversible Kodi/Emby sidecar jobs.
- [Flight Search Matrix](https://github.com/jedison/flight-search-matrix) — a local Chrome extension for repeatable award and fare research, with retained evidence and deliberately conservative provider adapters.

More projects will appear here as they reach a useful, public-ready state.
